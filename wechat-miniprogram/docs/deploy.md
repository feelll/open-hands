# 微信小程序发布部署指南

## 🎯 发布步骤详解

### 第一步：准备工作

#### 1.1 注册小程序账号
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 点击"立即注册" → 选择"小程序"
3. 填写账号信息并完成邮箱验证
4. 完成身份认证（个人或企业）
5. 获取小程序的 AppID

#### 1.2 安装开发工具
1. 下载 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
2. 安装并登录微信账号
3. 确保账号已绑定为小程序开发者

### 第二步：项目配置

#### 2.1 修改 AppID
在 `project.config.json` 文件中修改：
```json
{
  "appid": "你的小程序AppID"
}
```

#### 2.2 完善小程序信息
在微信公众平台设置：
- **小程序名称**: 太空射击游戏
- **小程序头像**: 上传游戏相关图标
- **小程序介绍**: 经典太空射击休闲游戏，操作简单，趣味无穷
- **服务类别**: 娱乐 → 休闲游戏

### 第三步：本地开发测试

#### 3.1 导入项目
1. 打开微信开发者工具
2. 选择"导入项目"
3. 项目目录选择 `wechat-miniprogram` 文件夹
4. 输入 AppID
5. 项目名称：太空射击游戏

#### 3.2 功能测试
测试以下功能是否正常：
- [ ] 游戏启动和初始化
- [ ] 飞船移动控制（触摸和按键）
- [ ] 射击功能
- [ ] 敌人生成和AI
- [ ] 碰撞检测
- [ ] 分数和等级系统
- [ ] 游戏结束和重新开始
- [ ] 最高分保存
- [ ] 分享功能

#### 3.3 性能优化
- 检查内存使用情况
- 确保帧率稳定在 30-60 FPS
- 测试不同设备的兼容性

### 第四步：代码上传

#### 4.1 版本管理
1. 在开发者工具中点击"上传"
2. 填写版本信息：
   - **版本号**: 1.0.0
   - **项目备注**: 太空射击游戏首个版本，包含完整游戏功能

#### 4.2 上传检查
确保上传前：
- 代码无语法错误
- 所有资源文件完整
- 功能测试通过
- 符合小程序规范

### 第五步：提交审核

#### 5.1 审核信息填写
在微信公众平台填写：

**功能页面**:
- 页面路径: `pages/game/game`
- 页面功能: 太空射击游戏主界面

**功能描述**:
```
这是一款经典的太空射击休闲游戏。玩家控制飞船在太空中射击敌人，获得分数。游戏特色：
1. 简单易上手的操作方式
2. 多种类型的敌人
3. 精美的视觉效果
4. 分数排行和成就系统
5. 适合所有年龄段的健康游戏内容
```

**测试账号**: 无需提供（游戏无需登录）

#### 5.2 审核要点说明
- **内容健康**: 游戏内容积极向上，无暴力血腥元素
- **操作流畅**: 触控操作响应及时，用户体验良好
- **功能完整**: 所有游戏功能正常运行
- **无违规**: 不包含违反小程序规范的内容

### 第六步：发布上线

#### 6.1 审核通过后
1. 在微信公众平台查看审核结果
2. 审核通过后点击"发布"
3. 小程序正式上线

#### 6.2 推广建议
1. **朋友圈分享**: 制作游戏截图和介绍
2. **微信群推广**: 在相关游戏群分享
3. **小程序码**: 生成小程序码用于线下推广
4. **内容营销**: 制作游戏攻略和技巧分享

## 🔍 审核常见问题

### 可能被拒绝的原因
1. **功能不完整**: 游戏有明显 bug 或功能缺失
2. **用户体验差**: 操作不流畅或界面混乱
3. **内容问题**: 虽然是射击游戏，但要确保内容健康
4. **技术问题**: 性能问题或兼容性问题

### 解决方案
1. **充分测试**: 在多种设备上测试游戏
2. **优化性能**: 确保游戏运行流畅
3. **完善文档**: 提供清晰的功能说明
4. **及时修复**: 发现问题立即修复并重新提交
