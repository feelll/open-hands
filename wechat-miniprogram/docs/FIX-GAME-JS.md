## 🛠️ 常见问题排查

### 1. 文件路径问题
确保 `app.json` 中的页面路径正确：
```json
{
  "pages": [
    "pages/game/game"
  ]
}
```

### 2. 文件完整性检查
确保每个页面都有4个必需文件：
- `game.js` (页面逻辑)
- `game.json` (页面配置)
- `game.wxml` (页面结构)
- `game.wxss` (页面样式)

### 3. 语法错误检查
使用开发者工具的语法检查功能：
- 详情 → 本地设置 → 启用 ES6 转 ES5
- 详情 → 本地设置 → 启用样式补全

### 4. 基础库版本
确保使用兼容的基础库版本：
- 当前设置: 3.0.2
- 最低要求: 2.19.4
