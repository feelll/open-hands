# 网站数据分析器

一个强大的网站数据分析工具，可以输入任何网址，自动抓取并分析网站数据，提供深度洞察报告。

## 功能特色

### 🔍 数据抓取
- 支持静态和动态网站内容抓取
- 智能提取文本、图片、链接等元素
- 可选择使用Selenium处理JavaScript渲染的页面

### 📊 数据分析
- **搜索词分析**: 提取高频关键词，分析用户搜索行为
- **用户喜好分析**: 分析内容类型偏好和媒体偏好
- **智能分类**: 自动识别网站内容类别（技术、商业、教育等）
- **情感分析**: 分析内容的情感倾向
- **内容结构分析**: 分析页面结构和内容密度

### 📈 数据可视化
- 交互式图表展示分析结果
- 词云图生成
- 多维度数据对比
- 响应式设计，支持移动端

### 📋 报告生成
- 生成详细的分析报告
- 支持报告历史记录
- 可视化数据展示
- 一键分享和导出

## 技术栈

### 后端
- **Flask**: Web框架
- **BeautifulSoup**: HTML解析
- **Selenium**: 动态内容抓取
- **Pandas**: 数据处理
- **Scikit-learn**: 机器学习分析
- **Jieba**: 中文分词

### 前端
- **Bootstrap 5**: UI框架
- **Plotly**: 交互式图表
- **Font Awesome**: 图标库
- **原生JavaScript**: 交互逻辑

### 数据可视化
- **Matplotlib**: 静态图表
- **Seaborn**: 统计图表
- **WordCloud**: 词云生成
- **Plotly**: 交互式图表

## 安装和运行

### 1. 安装依赖
```bash
cd web-data-analyzer
pip install -r requirements.txt
```

### 2. 运行应用
```bash
python app.py
```

### 3. 访问应用
打开浏览器访问: `http://localhost:12000`

## 使用方法

### 基本使用
1. 在首页输入要分析的网站URL
2. 选择是否使用高级抓取（适用于动态网站）
3. 点击"开始分析"按钮
4. 等待分析完成，查看详细报告

### 高级功能
- **动态网站分析**: 勾选"使用高级抓取"选项
- **历史报告**: 在首页查看最近的分析报告
- **详细报告**: 点击报告链接查看完整分析结果

## 分析功能详解

### 搜索词分析
- 提取网站中的高频关键词
- 分析词汇频率分布
- 生成词云图
- 识别核心主题词汇

### 用户喜好分析
- **内容类型偏好**:
  - 结构化内容 (有层次的标题结构)
  - 详细文章 (长篇内容)
  - 视觉内容 (图片丰富)
  - 参考密集 (链接较多)

- **媒体偏好分布**:
  - 文本内容比例
  - 图片内容比例
  - 链接内容比例

### 智能分类
支持以下内容分类:
- 技术 (Technology)
- 商业 (Business)
- 教育 (Education)
- 娱乐 (Entertainment)
- 健康 (Health)
- 新闻 (News)
- 体育 (Sports)
- 旅游 (Travel)

### 情感分析
- 分析内容的情感倾向
- 统计积极/消极词汇
- 计算情感得分
- 提供情感标签

## API接口

### POST /analyze
分析网站数据
```json
{
  "url": "https://example.com",
  "use_selenium": false
}
```

### GET /report/<report_id>
查看分析报告

### GET /api/reports
获取报告列表

## 配置说明

### 环境要求
- Python 3.7+
- Chrome浏览器 (用于Selenium)
- 足够的内存用于数据处理

### 可选配置
- 修改`app.py`中的端口号
- 调整分析参数
- 自定义分类关键词
- 扩展情感词典

## 注意事项

1. **网站访问**: 确保目标网站允许爬虫访问
2. **性能考虑**: 大型网站分析可能需要较长时间
3. **内存使用**: 复杂页面可能消耗较多内存
4. **法律合规**: 请遵守网站的robots.txt和使用条款
