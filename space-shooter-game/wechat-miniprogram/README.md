# 太空射击游戏 - 微信小程序版本

## 📱 项目简介

这是太空射击游戏的微信小程序版本，完全适配了微信小程序的技术架构和交互方式。

## 🚀 快速开始

### 1. 环境准备
- 下载并安装 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)
- 注册微信小程序账号并获取 AppID

### 2. 项目导入
1. 打开微信开发者工具
2. 选择"导入项目"
3. 选择本项目的 `wechat-miniprogram` 文件夹
4. 输入你的 AppID（在 `project.config.json` 中修改）
5. 点击"导入"

### 3. 本地调试
- 在微信开发者工具中点击"编译"
- 使用模拟器或真机预览进行测试

## 🎮 游戏特色

### 移动端优化
- **触控操作**: 支持触摸屏幕移动飞船
- **虚拟按键**: 提供方向键和射击按钮
- **手势射击**: 触摸结束时自动射击
- **暂停功能**: 适合移动端的暂停/继续机制

### 小程序特性
- **本地存储**: 自动保存最高分记录
- **分享功能**: 支持分享给好友或群聊
- **响应式设计**: 适配不同尺寸的手机屏幕
- **性能优化**: 针对小程序环境优化的渲染性能

## 📋 发布流程

### 1. 完善小程序信息
在微信公众平台（mp.weixin.qq.com）完善以下信息：
- 小程序名称：太空射击游戏
- 小程序简介：经典的太空射击休闲游戏
- 小程序图标：建议使用游戏相关的太空主题图标
- 服务类别：娱乐 > 游戏

### 2. 代码审核准备
确保代码符合微信小程序规范：
- ✅ 无违规内容
- ✅ 无外部链接跳转
- ✅ 用户隐私保护合规
- ✅ 游戏内容健康向上

### 3. 上传代码
1. 在微信开发者工具中点击"上传"
2. 填写版本号和项目备注
3. 上传成功后在微信公众平台查看

### 4. 提交审核
1. 登录微信公众平台
2. 进入"版本管理"
3. 选择刚上传的版本
4. 点击"提交审核"
5. 填写审核信息：
   - 功能页面：pages/game/game
   - 功能描述：太空射击游戏，玩家控制飞船射击敌人

### 5. 发布上线
- 审核通过后点击"发布"
- 小程序即可在微信中搜索到

## 🎯 操作说明

### 控制方式
1. **触摸移动**: 手指在屏幕上滑动控制飞船移动
2. **虚拟按键**: 使用屏幕下方的方向键
3. **射击**: 点击红色射击按钮或触摸结束时自动射击
4. **暂停**: 点击右上角暂停按钮

### 游戏目标
- 控制飞船躲避敌人攻击
- 射击消灭不同类型的敌人
- 获得更高的分数和等级
- 挑战个人最高分记录

## 🔧 技术架构

### 核心技术
- **Canvas 2D**: 使用微信小程序的 Canvas 2D API
- **触控事件**: 适配移动端的触摸操作
- **本地存储**: 使用 wx.getStorageSync 保存游戏数据
- **分享API**: 集成微信分享功能

### 性能优化
- 减少粒子数量以适配移动设备性能
- 优化渲染循环，避免不必要的重绘
- 合理控制敌人生成频率
- 及时清理离屏对象

## 📱 适配说明

### 屏幕适配
- 使用 rpx 单位确保不同设备的显示一致性
- Canvas 尺寸根据设备像素比自动调整
- UI 元素采用相对定位和弹性布局

### 交互适配
- 触控操作替代键盘输入
- 增加虚拟按键提供精确控制
- 优化触摸反馈和视觉效果

## 🚨 注意事项

### 审核要点
1. **内容合规**: 确保游戏内容积极健康
2. **功能完整**: 所有功能都能正常使用
3. **用户体验**: 操作流畅，界面美观
4. **性能稳定**: 无卡顿、崩溃等问题

### 常见问题
1. **Canvas 渲染问题**: 确保正确设置 Canvas 尺寸和像素比
2. **触控延迟**: 优化事件处理逻辑，减少延迟
3. **内存占用**: 及时清理不用的对象，避免内存泄漏
