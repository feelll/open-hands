## 🚀 快速开始

### 1. 环境准备
```bash
# 安装依赖
pip install -r requirements.txt

# 配置微信公众号（可选）
cp .env.example .env
# 编辑 .env 文件，填入微信公众号信息
```

### 2. 基本使用
```bash
# 检查配置
python main.py --check-config

# 下载图片（所有分类）
python main.py --download

# 下载指定分类
python main.py --download --category xgmn

# 上传到微信公众号
python main.py --upload

# 完整流程（下载+上传）
python main.py
```

### 3. 演示功能
```bash
# 运行功能演示
python demo.py

# 启动Web演示界面
python web_demo.py
# 访问 http://localhost:12001
```

## 🔧 故障排除

### 常见问题

1. **下载失败**
   - 检查网络连接
   - 确认目标网站可访问
   - 查看scraper.log了解详细错误

2. **上传失败**
   - 检查微信公众号配置
   - 确认AppID和Secret正确
   - 验证网络访问微信API

3. **权限问题**
   - 确保有写入downloads目录的权限
   - 检查日志文件的写入权限

### 调试方法
```bash
# 检查配置
python main.py --check-config

# 查看详细日志
tail -f app.log
tail -f scraper.log
```
