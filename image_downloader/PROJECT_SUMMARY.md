# 图片下载和微信公众号上传工具 - 项目总结

## 项目概述

本项目是一个完整的图片下载和微信公众号上传解决方案，专门针对 3gbizhi.com 网站的美女图片分类进行自动化下载和管理。

## 核心功能

### 1. 图片下载功能
- ✅ 自动解析网站分类页面
- ✅ 提取图片详情页链接
- ✅ 下载高质量图片
- ✅ 按分类自动整理到不同目录
- ✅ 支持断点续传，避免重复下载
- ✅ 智能过滤无效图片链接

### 2. 微信公众号上传功能
- ✅ 自动获取微信公众号 access_token
- ✅ 批量上传图片到素材库
- ✅ 支持临时素材和永久素材
- ✅ 详细的上传日志记录
- ✅ 素材库统计功能

### 3. 分类管理
支持以下8个图片分类：
- 性感美女 (xgmn)
- 美女写真 (mnxz)
- 日韩美女 (yzmn)
- 欧美美女 (ommn)
- 美女照片 (mnzp)
- 外国美女 (wgmn)
- 比基尼美女 (bjnmn)
- 翘臀美女 (dmmn)

## 使用示例

### 基本使用
```bash
# 检查配置
python main.py --check-config

# 下载所有分类
python main.py --download

# 下载指定分类
python main.py --download --category xgmn

# 上传到微信公众号
python main.py --upload

# 完整流程
python main.py
```

### 高级使用
```bash
# 指定分类的完整流程
python main.py --category xgmn

# 仅上传已下载的图片
python main.py --upload --category mnxz
```

## 配置说明

### 基础配置
- `MAX_IMAGES_PER_CATEGORY`: 每分类最大下载数量
- `DELAY_BETWEEN_REQUESTS`: 请求间隔时间
- `MAX_WORKERS`: 并发线程数

### 微信配置
需要在 `.env` 文件中配置：
```
WECHAT_APPID=your_wechat_appid
WECHAT_SECRET=your_wechat_secret
```

3. **权限错误**: 确保程序有读写目录的权限

### 调试方法
1. 查看详细日志文件
2. 使用 `--check-config` 验证配置
