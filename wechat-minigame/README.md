# 🎮 太空射击微信小游戏

## 📋 项目说明

这是一款专为微信小游戏平台开发的太空射击游戏，使用Canvas 2D API实现高性能游戏渲染。

## 🎯 小游戏 vs 小程序的区别

### 为什么选择小游戏平台？

| 特性 | 微信小程序 | 微信小游戏 ✅ |
|------|------------|---------------|
| **渲染性能** | WXML/WXSS (较慢) | Canvas 2D (高性能) |
| **游戏API** | 基础API | 专业游戏API |
| **包体大小** | 2MB 主包 | 4MB 主包 |
| **帧率** | 30FPS | 60FPS |
| **物理引擎** | 不支持 | 支持 |
| **音效** | 基础音频 | 游戏音效API |
| **审核类别** | 工具类审核 | 游戏内容审核 |

## 🚀 发布到小游戏平台

### 第一步：注册小游戏
1. 访问 [微信公众平台](https://mp.weixin.qq.com/)
2. 注册账号并选择 **"小游戏"** 类型（不是小程序！）
3. 完成资质认证
4. 获取小游戏 AppID

### 第二步：开发者工具设置
1. 下载 [微信开发者工具](https://developers.weixin.qq.com/minigame/dev/devtools/download.html)
2. 创建新项目时选择 **"小游戏"** 项目类型
3. 导入本项目的 `wechat-minigame` 目录

### 第三步：项目配置
修改 `project.config.json` 中的 AppID：
```json
{
  "compileType": "game",  // 注意：这里是 "game" 不是 "miniprogram"
  "appid": "你的小游戏AppID"
}
```

### 第四步：游戏分类设置
在微信公众平台设置：
- **游戏类型**: 休闲游戏
- **游戏标签**: 射击、太空、休闲
- **适龄提示**: 3+ (适合所有年龄)
- **游戏简介**: 经典太空射击游戏，操作简单，画面精美

### 4. 发布上线
审核通过后：
1. 点击"发布"
2. 游戏正式上线
3. 用户可以搜索到
