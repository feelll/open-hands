## 🔧 具体操作步骤

### 第一步：注册小游戏账号

1. **访问微信公众平台**
   ```
   https://mp.weixin.qq.com/
   ```

2. **选择注册类型**
   - 点击"立即注册"
   - ⚠️ **重要**：选择"小游戏"（不是小程序！）
   - 填写邮箱和密码

3. **完成认证**
   - 邮箱验证
   - 身份认证（个人或企业）
   - 获取AppID

### 第二步：配置开发环境

1. **下载开发者工具**
   ```
   https://developers.weixin.qq.com/minigame/dev/devtools/download.html
   ```

2. **创建项目**
   - 打开微信开发者工具
   - 选择"小游戏"项目类型
   - 导入`wechat-minigame`目录
   - 输入您的AppID

3. **修改配置文件**
   ```json
   // project.config.json
   {
     "compileType": "game",
     "appid": "您的小游戏AppID",
     "projectname": "space-shooter-minigame"
   }
   ```

### 第三步：游戏信息设置

在微信公众平台设置以下信息：

#### 分类设置

## ⚠️ 常见问题解决

### Q: 为什么不能发布到小程序？
A: 您的游戏使用Canvas渲染，需要高性能实时交互，属于游戏类应用，必须发布到小游戏平台。

### Q: 小游戏和小程序有什么区别？
A: 小游戏专门为游戏设计，支持Canvas 2D/WebGL，性能更好，包体更大；小程序主要用于工具和服务类应用。

### Q: 审核被拒怎么办？
A: 根据拒绝原因修改代码，常见问题包括性能问题、用户体验问题、内容问题等。

### Q: 如何提高审核通过率？
A: 确保游戏运行流畅、内容健康、操作简单、无明显Bug。
