# 太空射击游戏

一款使用HTML5 Canvas和JavaScript开发的休闲太空射击游戏。

## 游戏特色

- 🚀 流畅的太空飞船控制
- 💥 精美的爆炸特效
- ⭐ 动态星空背景
- 🎯 多种敌人类型
- 📊 实时分数和等级系统
- 🎮 简单易上手的操作

## 游戏玩法

### 控制方式
- **移动**: 使用 WASD 键或方向键控制飞船移动
- **射击**: 按空格键发射激光子弹
- **重新开始**: 游戏结束后点击"重新开始"按钮

### 敌人类型
1. **基础敌人** (红色) - 10分
   - 移动速度中等
   - 生命值: 1
   
2. **快速敌人** (橙色) - 20分
   - 移动速度快
   - 生命值: 1
   
3. **坦克敌人** (紫色) - 50分
   - 移动速度慢
   - 生命值: 3

### 游戏机制
- 玩家有3条生命
- 击败敌人获得分数
- 每500分提升一个等级
- 等级越高，敌人出现频率越高
- 被敌人子弹击中或撞击会失去生命

## 技术特点

- 使用HTML5 Canvas进行2D渲染
- 面向对象的JavaScript架构
- 流畅的60FPS游戏循环
- 粒子系统爆炸效果
- 响应式设计，支持不同屏幕尺寸
